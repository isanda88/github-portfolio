AWS Data

A comprehensive End-to-End Cloud Data Solution built on AWS to extract, transform, catalog, and visualize datasets without managing physical server infrastructure.

Key Architecture & Tools

  • Amazon S3: Scalable object storage for raw and processed datasets using lifecycle storage classes.
  • AWS Glue & Crawlers: Automated schema detection, metadata cataloging, and serverless ETL data integration.
  • AWS Glue DataBrew: Visual, code-free data cleaning, transformation recipes, and data quality checks.
  • Amazon Athena: Serverless ad-hoc SQL querying directly against S3 data using Workgroups for cost/access control.
  • AWS QuickSight: Interactive dashboards and data visualizations for insights extraction.
